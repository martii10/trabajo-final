Publicación de la Web

¿Qué es GitHub?

GitHub es una plataforma para almacenar proyectos y controlar versiones del código.

¿Qué es GitHub Pages?

GitHub Pages permite publicar sitios web de forma gratuita.

Pasos para publicar

  1. Crear repositorio.
  2. Subir archivos.
  3. Activar GitHub Pages.
  4. Obtener la URL pública.
